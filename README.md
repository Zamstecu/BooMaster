# 🎮 Local Multiplayer Game BoomMaster

**Local Multiplayer Game BoomMaster** adalah aplikasi pengoptimasi sistem yang dirancang khusus untuk meningkatkan performa perangkat saat menjalankan game multiplayer berbasis lokal (**LAN** atau **Couch Co-op / Split-Screen**). 

Tidak seperti game booster konvensional yang berfokus pada ping internet, aplikasi ini berfokus pada **stabilitas FPS, alokasi RAM/CPU, dan minimalisasi *input lag*** dari banyak kontroler sekaligus.

---

## ✨ Fitur Utama

### 🧠 Otomatisasi Sistem (CPU & RAM)
* **Smart Resource Allocation:** Menghentikan proses latar belakang (*background apps*) yang tidak penting untuk memberikan prioritas penuh pada *game engine*.
* **RAM Cleaner:** Mengosongkan ruang memori sebelum game multiplayer diluncurkan.

### 🔌 Pengoptimal Jaringan Lokal (LAN)
* **Traffic Prioritization:** Memastikan paket data antar perangkat dalam jaringan LAN lokal berjalan dengan prioritas tertinggi untuk mencegah *stuttering*.
* **Zero Packet Loss Optimization:** Mengoptimalkan pengaturan *network adapter* untuk stabilitas koneksi lokal.

### 🎮 Manajemen Kontroler & Input Lag
* **Input Latency Reduction:** Mempercepat waktu respons antara penekanan tombol pada kontroler (Gamepad/Keyboard) ke sistem.
* **Multi-Controller Bridge:** Memastikan driver untuk banyak kontroler (hingga 4 pemain atau lebih) tetap berjalan stabil tanpa konflik.

---

## 📊 Perbandingan Fokus Optimasi

| Fitur | Game Booster Biasa | Local Game Booster |
| :--- | :---: | :---: |
| **Fokus Utama** | Koneksi Server Cloud / Online | Performa Hardware & LAN |
| **Optimasi Ping** | Ya (Mengubah rute DNS/VPN) | Tidak (Hanya menstabilkan lalu lintas lokal) |
| **Input Lag Multi-Device** | Tidak Terlalu Diperhatikan | **Sangat Diprioritaskan** |
| **Render Split-Screen** | Standar | **Dioptimalkan (Mencegah FPS Drop)** |
